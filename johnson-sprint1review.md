This week I worked on the front-end and back-end of the "User feedback" functionality. I designed a form in html with a binary choice for the user followed by an option for elaboration. 
I chose a binary "Do you like it? Yes/no" because I wanted it to be as simple as possible for the user to decide, and it would be more simple than figuring out stars or something else.
For the backend I simply made a table schema generation command and added it to the end of our current sql table set up.
